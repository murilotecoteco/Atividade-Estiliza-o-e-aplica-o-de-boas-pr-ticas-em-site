# Painel de Vendas

Projeto de uma loja virtual simples, desenvolvido para praticar estilização
responsiva, organização de interface e boas práticas de desenvolvimento web.

## Demonstração

Acesse o projeto publicado no GitHub Pages:

**[Abrir o Painel de Vendas](https://murilotecoteco.github.io/Atividade-Estiliza-o-e-aplica-o-de-boas-pr-ticas-em-site/)**

## Funcionalidades

- Exibição dos produtos em cards responsivos.
- Apresentação de nome, preço e quantidade disponível em estoque.
- Registro de vendas com atualização imediata do estoque.
- Desativação do botão quando um produto fica esgotado.
- Histórico de atividades com indicação visual de sucesso ou erro.
- Ícones dos produtos utilizando a biblioteca Lucide Icons.

## Produtos disponíveis

- Caderno
- Lápis
- Borracha
- Mochila

Cada produto começa com 10 unidades em estoque.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- [Lucide Icons](https://lucide.dev/)

## Como executar localmente

1. Clone este repositório:

   ```bash
   git clone https://github.com/murilotecoteco/Atividade-Estiliza-o-e-aplica-o-de-boas-pr-ticas-em-site.git
   ```

2. Acesse a pasta do projeto:

   ```bash
   cd Atividade-Estiliza-o-e-aplica-o-de-boas-pr-ticas-em-site
   ```

3. Abra o arquivo `index.html` no navegador.

Também é possível utilizar uma extensão de servidor local, como o Live Server,
para visualizar o projeto durante o desenvolvimento.
